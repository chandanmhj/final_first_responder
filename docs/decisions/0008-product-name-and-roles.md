# 0008. Product name First Responder; three user roles

- Status: Decided
- Decided by: Chandan
- Date: 2026-10-06

## Context
Name and who the app serves.

## Decision
The product is called First Responder. Users are bystanders or the patient themselves, and the steps depend on the user's responsibility (bystander, self, first responder).

## Consequences
Role-dependent step lists. See docs/architecture/roles-and-reports.md.
