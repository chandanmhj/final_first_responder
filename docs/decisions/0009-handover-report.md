# 0009. Generate a time-stamped handover report

- Status: Decided
- Decided by: Chandan
- Date: 2026-10-06

## Context
First responders need to know what happened.

## Decision
When help arrives, a report of what happened and the time of each event is generated for the first responders.

## Consequences
Needs an event log. Follows the handbook's ISBAR format (Proposed).
