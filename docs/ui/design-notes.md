# UI design notes

Reference: `docs/ui/reference/chat-layout-v1.png`, a screenshot of the Figma "LLM Chatbots (Community)" design.

## Take from the reference (Decided)
- Left sidebar with profile, search, navigation, starred and recent conversations, and a "new conversation" button.
- Welcome card with a single input and send button.
- Conversations list with search and relative timestamps.

## Remove (Decided)
- The "Model Type" dropdown.
- Model badges (GPT, Llama, Mistral) on each conversation row.

## Add
- Step cards with media, quick-reply buttons (Next / Not worked) and the text box.
- Image attach button.
- Hands-free mode control and full-screen overlay.
- Persistent "call emergency services" action.

## Open
- Exact fonts, colors and spacing: share the Figma file or Dev Mode values, or tell me to derive them from the screenshot.
- Dark mode (not requested yet).
