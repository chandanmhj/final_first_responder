# evaluation/

- `rag_eval/`: Python package with dataset loaders, RAG variants, metrics, runner, and report/figure generation.
- `notebooks/`: the notebooks that test each variant and draw the figures (00 to 09).
- `configs/`: experiment configurations.
- `cache/`: cached model outputs (git-ignored).

Outputs are written to `docs/evaluation/figures/` and `docs/evaluation/results/`. See `docs/evaluation/methodology.md`.
